OpenZiti Enrollment Instructions

  1. 1

    Install OpenZiti Client

    Download and install the **OpenZiti Desktop Edge** client for your operating system (Downloads Page).

  2. 2

    Download Token

    Download the enrollment token (`zt-host-client.jwt`) using the button in the Zero-Trust card.

  3. 3

    Add Identity

    Open your OpenZiti Desktop Edge client, click **"Add Identity"** (or the **+** button), and select the downloaded `.jwt` file.

  4. 4

    Access Secure App

    The client will automatically perform enrollment and bind `zt-app-secure-ui`. You can now access the app directly via http://zt-app-local:8080!
